# SLauncher

스타크래프트 리마스터 (StarCraft: Remastered)

---

## SLauncher:

### 전체
- 실시간 날짜 · 시간(`YYYY/MM/DD HH:MM:SS`) 및 SDetector 작동 표시 (ON / OFF 및 위치 이동 가능)
- 핵 사용자 및 악성 사용자 서버 연동 · 블랙리스트 사전 판별 안내
- Battle.net 데스크톱 앱 로그인 계정 자동 인식 (별도 웹 브라우저 로그인 불필요)
- `컨트롤 + H` 로 런처 도우미 제어 (숨김 / 표시)

### 게임내
- 스타크래프트 멀티플레이에서 핵 사용 및 비정상 패킷을 실시간으로 감지합니다.
- 드랍창이 떴을 때 빠른 디스 타이머 보호 및 디스 대기시간 단축 패치를 지원합니다.
- 플레이어의 핑(`Ping`)과 손속도(`APM / EAPM`), 종족, 전적, 승률을 실시간으로 볼 수 있습니다. (정교한 수치)
- 미니맵 핑이 플레이어 실제 색상으로 변경되며(`StarPing`), 핑 발신자 전체 알림을 지원합니다.
- 단축키(`알트 + 1~8`)로 원하는 사용자의 채팅을 즉시 차단 / 해제할 수 있습니다.
- 블랙리스트로 원하는 사람을 판별하며, 게임 시작 후 중도 이탈자(탈주자) 자동 블랙리스트 등록을 지원합니다.
- 게임 중 귓속말 숨김 및 전체 방해금지 모드 지원
- 관전자(옵저버)일 때 플레이어 모니터 패널(`F7` / `키패드 0`)에서 관전자 전체 채팅 전환 가능 (리플레이 · 래더 제외)

### 로비
- 방 목록 자동 새로고침(2초~60초 주기), 마지막 입장 방 상단 고정 · 강조, 친구 방 / 최근 방 / 차단 방 분류
- Full 방 · 비번방 · 리플레이 방 숨김 및 방 제목 · 맵 이름 · 방장 이름 키워드 필터링
- 비밀번호 방이 의도치 않게 공개방으로 풀리는 현상 자동 방지 및 방 입장 렉 완화
- 로비 닉네임 우측 실시간 플레이어 핑(`ms`) 자동 표시 및 과거 조우 히스토리 출력
- 블랙리스트로 원하는 사람을 자동 판별 가능 (`BattleTag` · 닉네임 · 고유 식별값 교차 추적)
  - 방장일 경우 자동 강퇴 (`화이트리스트` 등록 사용자는 최우선 예외 처리)
  - 방장이 아닐 경우 블랙리스트 사용자 경고 표시
- `컨트롤 + L` 로 로비 플레이어 / 관전자 슬롯 리스트 ON / OFF
- 방제목에 `~50%`, `50%~`, `50%~60%`, `이상`, `이하` 키워드가 있을 경우 승률 조건 자동 감지
- 방제목에 `#공평` 키워드가 있을 경우 전적을 분석해서 승률이 맞도록 최적의 팀 구성 제안

---

## 실행방법:
Battle.net 데스크톱 앱 로그인 상태에서 `SLauncher` 실행 후 **`Battle.net 실행`** 클릭 → 배틀넷 공식 **`플레이`** 버튼으로 스타크래프트 실행 (자동 연결)

---

## 사용방법:

### 로비
- `컨트롤 + L` : 로비 플레이어 / 관전자 슬롯 리스트 보기, 끄기

### 게임내
- `F7` : 플레이어 모니터 패널 보기, 끄기 (종족, 전적, 승률, APM/EAPM, 핑/렉 확인 및 관전자 전체 채팅 전환)
- `키패드 0` : 플레이어 모니터 패널만 단독 보기, 끄기 (SDetector 및 시계 설정 유지)
- `` ` `` (숫자 1 왼쪽 키) : 플레이어 커스텀 색상 즉시 켜기, 끄기 (도우미에서 색상별 개별 커스텀 단축키 지정 가능)
- `컨트롤 + 알트 + 마우스 드래그` : 시계 및 플레이어 모니터 위치 이동
- `쉬프트 + 알트 + D` : 디스 타이머 패치 제어
- `F12` : GameInput 입력 보조 종료

### 공통
- `알트 + 1~8` : 해당 번호 플레이어 채팅 차단 / 해제 (이그노어)
- `컨트롤 + H` : SLauncher 도우미 보기, 끄기

## 핵 방지:
- 드랍핵
- 로비 크래쉬 (방폭핵 선차단)
- 비정상 패킷 및 악성 귓속말 크래쉬 차단
- 외부 비인가 핵 도구 동시 실행 차단
- 지정 유즈맵 외부 배속 및 `#X` 방제 배속 변조 차단 (원본 맵 자체 EUD 배속은 정상 허용)

- 오토마인
- 멀티커맨드
- 오토빌드

## 기타:
- 정교한 실시간 핑 상태 보기 (로비 & 인게임)
- 핵 감지 시 배틀태그(`BattleTag`) 및 이벤트 로그 노출
- 해외 / VPN 접속자 로비 자동 강퇴 옵션
- 사용자 채팅 차단 및 방 제목 · 맵 키워드 광고방 필터링
- 사용자 블랙리스트 / 화이트리스트 (닉네임 변경 추적 및 사유 메모 지원)
- 미니맵 핑 플레이어 색상 표시 (`StarPing`) 및 핑 발신자 전체 알림
- 같은 방 동일 회선(엔드포인트) 사용자 확인 지원
- 실시간 날짜 · 시간 시계 표시
- 유저 조우 히스토리 자동 기록 및 관리 (JSON / CSV 가져오기 · 내보내기)
- 공방 게임 플레이 기록 및 로비 · 인게임 전체 채팅 로그 자동 저장
- 디스 카운트 15초 단축 패치 및 15초 장시간 렉 자동 차단
- 게임 시작 후 중도 이탈자 자동 블랙리스트 등록
- 사용자 커스텀 색상 지정 (AUTO / 전체 단일색 / 전체 랜덤 / 슬롯별 지정)
- 친구 방 및 최근 입장 방 올리기 · 마지막 입장 방 상단 고정
- 동맹 / 비동맹 채팅 구분 표시 및 로비 입장 자동 환영 문구
- Battle.net 친구 목록 · 귓속말 인게임 실시간 연동 (`Friends Service`)
- 커스텀 `GRP` 그래픽 스킨(999 Image ID) 항시 적용 · 미리보기 · 맵 내장
- Battle.net 호환 지형 타일(`MTXM`) 편집기 및 원본 검증 `맵 클라우드` · `1:1 문의`

## 안내:
- SLauncher 사용자가 방 안에 많을수록 드랍 및 방폭을 방어할 확률이 높아집니다.
- 핵 사용자를 제외한 모두가 런처를 사용할 시 방어 효율이 대폭 향상됩니다.
- 로비 크래쉬(방폭) 공격을 막아낸 직후에는 안정적인 진행을 위해 새로 방을 만드는 것을 추천합니다.
- 심한 디스가 걸리거나 네트워크 렉이 있을 경우 정상적인 유저의 패킷 지연이 이상 징후로 기록될 수 있으니, 패킷 분석 기록과 전후 상황을 함께 참고하여 판단하시기 바랍니다.
- 공정한 게임 환경 보호를 위해 핵심 보안 가드(`Rust 보안 가드 + SEngine + PacketGuard`)는 필수 ON으로 동작하며 임의로 끌 수 없습니다. (정식 등록된 일반 오토마우스는 자동 차단 대상에서 제외됩니다.)
- 블랙리스트에 등록된 멤버는 사용자가 방장일 때 로비에서 자동 강퇴되며, 방장이 아닐 경우에는 경고 안내가 표시됩니다. (화이트리스트 등록 사용자는 우선 허용됩니다.)
- 이그노어(`알트 + 1~8`)를 설정한 후 다시 해제할 경우 차단 중 입력된 채팅이 한 번에 표시될 수 있습니다.

## 방제목 설정 안내:
- **승률 조건 설정**: 방제목에 `~xx%`, `xx%~`, `xx%~yy%`, `이상`, `이하` 키워드가 있을 경우 자동으로 승률 조건을 감지합니다. 가끔 배틀넷 서버 문제로 사용자들의 전적을 가져오지 못할 경우 실행되지 않을 수 있습니다.
  - 예) `빨무 50%~` 또는 `빨무 승률 50 이상` : 승률 50% 이상 조건 자동 인식
  - 예) `빨무 50%~60%` : 승률 50% ~ 60% 구간 조건 자동 인식

- **`#공평` 키워드**: 방제목에 `#공평`을 붙일 경우 참가자들의 전적을 분석해 승률 균형이 비슷해지도록 최적의 팀 구성을 제안해 줍니다. 가끔 배틀넷 문제로 사용자들의 전적을 가져오지 못할 경우 실행되지 않을 수 있습니다.
  - 예) `빨무 #공평` : 자동으로 승률 밸런스를 맞춰 팀 구성을 분석해 줍니다.
