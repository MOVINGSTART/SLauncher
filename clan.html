1.16.1 피쉬서버 등급 · 명령어 구성 (예정)

과거 피쉬서버 Op 채널에서 쓰이던 직관적인 권한 체계와 슬래시 명령어 레이아웃입니다.

🔨 Master (클랜장) 🔨 Op (관리자) ★ VOp (부관리자) SCX Member (클랜원)
  • /clan list 클랜원 전체 명단 및 현재 온라인·접속 방 상태 확인
  • /clan set 소속 클랜의 Op 채널을 기본 입장 채널로 지정
  • /clan msg [내용] 접속 중인 클랜원 전체에게 클랜 공지·내전 호출 전송
  • /clan give [ID] op 클랜원 등급 변경 (op / vop / none) 및 채널 관리 권한 부여
