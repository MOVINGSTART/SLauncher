GRP 적용법

일반 그림 파일(PNG·GIF)부터 리마스터 전용 .anim 스킨, 지형 타일, Iscript·콘솔 UI까지 S런처 안에서 몇 번의 클릭으로 안전하게 적용하고 미리보는 방법입니다.

적용 방식 GRP 맵 전용
Image 카탈로그 999 ID
지원 화질 HD + SD
1
대상 선택 · 파일 추가 『맵 리소스 적용』 탭에서 유닛 이름을 검색해 이미지/ANIM 파일을 등록하거나 분류 폴더에 넣습니다.

스타 실행 · 인게임 자동 적용 유즈맵 이름과 무관하게 모든 방에서 자동 적용되며, 토글 OFF 하나로 언제든 순정 복구됩니다.

STEP 01

기본 원리 및 지원 파일 형식

원본 맵 무수정

S런처의 GRP 그래픽 기능은 개별 유즈맵(.scx / .scm) 파일을 건드리지 않고 전역 UserAssets 및 RuntimeMod 경로를 통해 동작하므로, 공방·밀리·유즈맵 파일명이 무엇이든 항상 동일하게 적용됩니다.

일반 그림 파일 (자동 변환) .png · .jpg · .gif · .bmp · .webp

따로 변환 툴을 쓸 필요 없이 999 Image ID 빌더에서 선택하면 HD/SD .anim 스프라이트로 즉시 자동 변환됩니다.

스타 리마스터 스킨 파일 main_000.anim ~ main_998.anim

커뮤니티에서 배포되는 HD/SD 유닛·건물·투사체·기타 .anim 스킨 및 지형 타일 자산을 그대로 등록할 수 있습니다.

스크립트 · 콘솔 UI 확장 iscript.bin · ConsoleUI (rez/game)

검증된 단일 iscript.bin 애니메이션 스크립트와 허용된 콘솔 UI 스킨도 동일한 RuntimeMod 경로로 안전하게 동기화됩니다.

STEP 02

999 Image ID로 개별 스킨 바로 적용하기 (권장)

가장 쉬운 방법

파일 이름 규칙(`main_XXX.anim`)을 외울 필요 없이, S런처 내장 EUD Editor 기준 999개 Image 카탈로그에서 한글·영문 이름으로 검색해 바로 입힐 수 있습니다.

  1. 1
    『맵 리소스 적용』 메뉴 열기 & 스위치 확인

    S런처 좌측 사이드바에서 『맵 리소스 적용』 탭을 클릭하고, 상단 『1. GRP 항시 적용』 카드의 『GRP 그래픽 활성화』 스위치가 ON 상태인지 확인합니다.

  2. 2
    원하는 유닛·건물·이펙트 검색 (0 ~ 998)

    『2. 999 Image ID』 영역에서 분류(전체 / 유닛 203 / 건물 182 / 투사체·효과 287 / 기타 327)를 고르거나 검색창에 『마린』, 『히드라』, 『게이트웨이』, 『239』처럼 이름 또는 번호를 입력해 대상을 선택합니다.

  3. 3
    파일 종류에 맞는 적용 버튼 클릭

    우측 『커스텀 이미지 적용』 영역에서 준비한 파일 형식에 맞는 버튼을 누릅니다. 일반 그림(PNG/GIF 등)은 『이미지 → 유닛 / 건물 / 투사체 / 기타』를, 이미 만들어진 .anim 파일은 『ANIM → 유닛 / 건물 / 투사체 / 기타』를 선택하면 HD와 SD 자산이 함께 동기화됩니다.

  4. 4
    『RuntimeMod 즉시 동기화』 확인

    자산 추가 시 자동으로 반영되며, 상단 『RuntimeMod 즉시 동기화』 버튼을 한 번 눌러주면 『맵 GRP 프로필』 상태창에서 적용된 ANIM 개수와 대상 Image 수를 즉시 확인할 수 있습니다.

STEP 03

분류 폴더에 스킨 팩 한꺼번에 넣기

대량 스킨 팩

여러 개의 `.anim` 파일로 구성된 통합 스킨 팩을 보유하고 있다면, S런처의 분류별 전용 폴더에 복사해 한 번에 동기화할 수 있습니다.

  • 폴더 상단 버튼 줄의 『Unit 폴더』, 『Building 폴더』, 『Projectile 폴더』, 『Other 폴더』, 『Tile 폴더』, 『SD 폴더』 버튼을 누르면 해당 UserAssets 폴더가 탐색기에서 바로 열립니다.
  • 중요 카테고리 격리 규칙: 각 `.anim` 파일의 Image ID는 반드시 해당 카탈로그 분류 폴더에 넣어야 합니다. (예: 건물 ID 파일을 Unit 폴더에 넣으면 정합성 검사가 안내하며 적용을 멈춥니다.)
  • 적용 파일 복사를 마친 뒤 S런처에서 『RuntimeMod 즉시 동기화』 또는 하단 『전체 리소스 다시 적용』 버튼을 누르면 모든 파일의 무결성 검사 후 일괄 적용됩니다.
STEP 04

GRP 미리보기에서 HD / SD 확인 및 개별 삭제

게임을 켜기 전에도 S런처 안에서 UserAssets에 실제 저장된 HD·SD·타일 프레임을 즉시 렌더링해 눈으로 확인하고 관리할 수 있습니다.

  • 확인 좌측 사이드바의 『GRP 미리보기』 탭(또는 999 Image ID 카드 하단의 『HD 미리보기』 / 『SD 미리보기』 버튼)을 누르면 실제 적용된 첫 프레임 이미지가 표시됩니다.
  • 조작 우측 상단 『HD / SD』 버튼으로 화질을 즉시 전환할 수 있고, 미리보기 스테이지에서 드래그·방향키·마우스 우클릭으로 스프라이트 이동 느낌까지 바로 테스트할 수 있습니다.
  • 삭제 우측 『적용된 자산 목록』에서 원하는 항목을 클릭해 전환해 보다가 마음에 들지 않는 스킨이 있다면 상단 『선택 삭제』 버튼으로 해당 스킨만 깔끔하게 지울 수 있습니다.
STEP 05

스타크래프트 인게임 확인 & 1초 순정 복구

  • 실행 S런처가 실행된 상태에서 Battle.net 앱의 『플레이(Play)』 또는 S런처 실행 버튼으로 StarCraft: Remastered에 접속하면 자동으로 프로세스를 감지해 GRP 자산을 연결합니다.
  • 화질 인게임 진입 후 『F5』 키로 HD 리마스터 그래픽과 SD 클래식 그래픽을 전환해도 양쪽 화질 모두 끊김 없이 동기화되며, S런처 상태 카드에 『실제 적용: 성공』 여부가 표시됩니다.
  • 복구 순정 그래픽으로 돌아가고 싶을 때: 넣어둔 스킨 파일을 일일이 삭제할 필요 없이 『GRP 그래픽 활성화』 토글만 OFF로 끄면 즉시 순정 상태로 돌아갑니다.
STEP 06

맵 제작자 내장 · 타일 편집 · 보안 검사

  • 내장 맵 파일에 직접 GRP 내장(선택사항): 특정 `.scx / .scm` 맵 자체에 GRP를 심어 배포하려는 제작자는 『SCX 선택』 후 『맵에 GRP 내장』 및 『실제 맵 트리거 테스트』 기능을 활용할 수 있습니다.
  • 지형 배틀넷 호환 타일 편집: 좌측 『타일 편집』 탭에서 `.scx / .scm`의 실제 MTXM 지형을 브러시(1×1 ~ 14×14)로 직접 수정·저장할 수 있으며, 첫 저장 전 원본 백업이 자동 생성됩니다.
  • 보안 위장 파일 자동 차단: 모든 스킨·Iscript(`iscript.bin` 단독 허용)·콘솔 UI 폴더는 적용 전 시그니처를 전수 검사하며, 실행파일(MZ/PE·ELF)이나 압축파일(ZIP·7z·RAR)이 하나라도 섞여 있으면 전체 적용을 즉시 차단해 PC를 보호합니다.
FAQ

자주 묻는 질문 · 문제 해결

Q. 스킨을 넣었는데 인게임에서 기본 유닛으로 그대로 나와요.

① 『GRP 그래픽 활성화』 토글이 ON인지 확인 후 『RuntimeMod 즉시 동기화』를 눌러주세요. ② 스타크래프트를 먼저 켜둔 상태에서 나중에 설정했다면 게임을 한 번 재실행하거나 인게임 F5 화질 전환을 확인하세요. ③ 입장한 방이 무단수정 의심(사기맵 해시 불일치)으로 감지된 경우 안전을 위해 해당 방에서는 GRP 연결이 자동 보류됩니다.

Q. 다른 사람 화면에도 내 커스텀 GRP 스킨이 보이나요? 방 갈림(디싱크)은 없나요?

GRP 그래픽 동기화는 내 화면의 렌더링 텍스처만 안전하게 교체하므로 게임 판정·유닛 데이터에 영향을 주지 않아 일반 배틀넷 유저와 함께 플레이해도 방 갈림(디싱크)이 발생하지 않습니다. (단, 맵 제작자가 『맵에 GRP 내장』으로 배포한 맵은 맵 자체 리소스를 따릅니다.)

Q. 현재 적용 중인 스킨을 파일로 다시 꺼내서 백업할 수 있나요?

가능합니다. 『2. 999 Image ID』 우측 카드의 『현재 적용 자산 추출』 영역에서 『추출 → 유닛/건물/투사체/기타』 또는 『타일 추출』을 누른 뒤 『추출 폴더 열기』를 클릭하면 자동 정리된 파일명으로 백업할 수 있습니다.
